# 자동차 경주

---

## 프로그램 동작 순서

1. 경주할 자동차의 이름을 입력받기 위한 안내 메시지를 출력한다.
    - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
2. 자동차의 이름을 입력받는다.
3. 시도할 횟수를 입력받기 위한 안내 메시지를 출력한다.
    - `시도할 횟수는 몇 회인가요?`
4. 시도할 횟수를 입력받는다.
5. 각 횟수 별로 실행 결과를 출력한다.
    - 횟수 별 실행 결과: `이름 : 현재위치(-)` 예시: `kang : --`
6. 최종 우승자를 출력한다.
    - 예시: `최종 우승자 : kang`, 2인 이상일 경우: `최종 우승자 : kang, min`

---

## 기능 목록

### 입출력

- [ ] 사용자 입력을 위한 안내 메시지 출력
    - [ ] `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
    - [ ] `시도할 횟수는 몇 회인가요?`
- [ ] 사용자를 통한 입력
    - [ ] 자동차 이름 문자열 입력
    - [ ] 시도할 횟수 0 이상의 정수 입력
    - [ ] `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용
- [ ] 결과 확인을 위한 출력
    - [ ] 실행 결과 출력 시 빈 줄 추가 (라운드 구분)
    - [ ] 각 횟수 별 실행 결과를 출력
    - [ ] 최종 우승자 출력
    - [ ] 최종 우승자 출력 전 빈 줄 추가

### 자동차 이름 전처리

- [ ] 공백 제거 처리
- [ ] `,` 기준으로 이름 구분

### 게임 진행

- [ ] 입력된 횟수만큼 라운드 진행
- [ ] 각 라운드마다 모든 자동차 이동
- [ ] 각 차수별 결과 출력

### 자동차 이동

- [ ] 0에서 9까지의 랜덤 숫자를 생성
    - `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용
- [ ] 값이 4 이상인 경우 자동차를 이동

### 자동차별 이동 거리 판별

- [ ] 현재 위치를 `-`로 출력

### 최종 우승자 판별

- [ ] 이동 거리가 가장 먼 자동차 판별
- [ ] 우승자가 여러 명일 경우 쉼표로 구분하는 기능

---

## 예외 처리

사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료

### 예외 발생 상황

- [ ] 입력받는 자동차 이름의 길이가 5자 초과인 경우
- [ ] 입력된 값이 없을 경우
- [ ] `" "`이 입력된 경우
- [ ] 이름을 쉼표로 구분하지 않은 경우
- [ ] 시도할 횟수의 숫자가 음수인 경우, 0인 경우
- [ ] 시도할 횟수가 Integer 범위를 초과하는 경우
- [ ] 시도할 횟수에 문자가 입력된 경우
